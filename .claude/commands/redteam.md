description: Two-sided assumption review — challenge the Base for over-optimism AND over-conservatism
---

Delegate to the **`skeptic` subagent** in a clean context. This is an **assumption
review, not a demolition** — the skeptic hunts *errors in reasoning*, and a Base
that sits **below demonstrated performance with no deterioration basis is as much an
error as an ungrounded bull** (CLAUDE.md Prime Directive 1; methodology #4). The
point is to *refine* the assumptions toward the honest centre, not to ratchet them
down. Give it the evidentiary base: `07-assumptions.md`, the SOTP build
(`07b-sotp.md` if present), `06-operating-drivers.md` (the growth attack MUST target
a primitive from its company build + competitor data), `05-industry-map.md`,
`04c-primary-financials.md` (the hard numbers + the multi-year trajectory),
`framework/methodology-checks.md`, and `framework/capex-supercycle-hybrids.md` (if a
build-ahead name).

Write `08-redteam.md`:

1. **Is the Base the honest centre? (both directions — do this FIRST).**
   - **Too optimistic where?** Inputs above what the evidence supports.
   - **Too conservative where?** Inputs *below* the company's demonstrated trajectory
     with no deterioration evidence — a growth fade steeper than penetration/mean-
     reversion warrants, a margin held flat while the leverage record shows expansion,
     a cash haircut on real distributable surplus, caution double-counted from a prior
     red-team pass. Name each and say what the evidence-consistent value is.
   - **Consistency audit:** is a single evidence source (guidance, track record)
     treated pessimistically on one input and optimistically on another? Flag it.
2. **Three credible bear cases** — each: the value-destroying mechanism, the leading
   indicator, rough probability. (These populate the *Bear*, not the Base.)
3. **Attack the four swing inputs** (Y1 growth, Y-end growth, terminal EBIT margin,
   discount rate) — for each, the defensible *range*: plausible adverse value AND
   plausible favourable value, with the evidence for each bound. The growth attack
   must target a SPECIFIC primitive (volume / price / share) from `06`, not a generic
   CAGR.
3b. **Grounded-fade test, both directions (do not skip).** Every bear number traces
   to *observable deterioration*; every base fade endpoint is held to the same
   standard.
   - A revenue CAGR below industry TAM growth must name the share-loss evidence.
   - A Base that fades a low-penetration compounder to mature-network growth, or holds
     margin flat against a demonstrated expansion record, must justify *why the
     demonstrated trend stops* — absent that, it is an ungrounded-DOWN error.
   - Anchor bear floors to mature comparables; flag any bear manufactured by
     over-steepening the in-window fade rather than a real deterioration thesis.
3c. **Build-ahead / terminal-heavy attacks** (see `framework/capex-supercycle-hybrids.md`):
   attack the discount rate explicitly (run the rate bridge); smuggled-bull check;
   margin-toward-a-falling-target check; re-centre a spread that is lopsided *either* way.
4. **Steelman the market** — the strongest counter to the thesis (not a strawman) —
   AND the strongest reason the market may be *under*-pricing the name.
5. **Underperformance test** — what must be true to lose to a global index over 10yr.
6. **Recommended assumption changes — BOTH directions.** Itemised edits to
   `07-assumptions.md`: which to move DOWN (over-optimism) and which to move UP
   (over-conservatism), each labelled **evidence-based** or **judgment**, so the
   analyst adjudicates a *centred* Base — not a systematically lower one.

The review is done well when it moves the Base toward the truth from whichever side
it was off — a spread that is too *narrow and high* and one that is too *wide and low*
are both failures it must catch.
